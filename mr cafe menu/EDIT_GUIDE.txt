  6. MENU ITEMS (add / edit / remove items)
================================================================

  FILE: script.js — Look for: const menuItems = [
  --------------------------------
  Each item looks like this:

    {
      id:       "cappuccino",         ← unique ID (no spaces)
      category: "coffee",             ← coffee / cold / tea / desserts / snacks
      popular:  true,                 ← true = shows "Popular" badge, false = no badge
      image:    "images/cappuccino.jpg",  ← path to image file (or leave as is)
      name: {
        en: "Cappuccino",
        ku: "کاپوچینۆ",
        ar: "كابتشينو"
      },
      desc: {
        en: "Espresso with steamed milk and foam",
        ku: "ئێسپریسۆ لەگەڵ شیر و فۆم",
        ar: "إسبريسو مع الحليب المبخر والرغوة"
      },
      price: "4,000 IQD"             ← change price here
    },

  TO ADD A NEW ITEM:
    Copy one of the blocks above, paste it inside the [ ] array,
    change the details, and save.

  TO REMOVE AN ITEM:
    Delete the entire { ... }, block for that item.

  TO CHANGE A PRICE:
    Find the item by its id or name, then change the price: "..." value.

  TO MARK AS POPULAR:
    Set popular: true

  9. HERO 3D MOVIE VIDEO SHAPES (Circular 3D Carousel)
================================================================

  FILE: index.html — Look for: <div class="hero-cards-track">
  --------------------------------
  Contains the 3 movie shapes (hc1, hc2, hc3).
  To put real videos inside any shape, add a <video> tag inside .hero-card:
    <div class="hero-card" id="hc1">
      <video src="images/your_video.mp4" autoplay loop muted playsinline></video>
    </div>

  FILE: style.css — Look for: .hero-card
  --------------------------------
  Video format: 16:9 Widescreen Movie Format (NOT vertical reels!)
  Sizes for the 3 devices:
    - Desktop: 380 × 214 px (aspect-ratio: 16 / 9)
    - Tablet:  310 × 175 px
    - Mobile:  240 × 135 px

  FILE: script.js — Look for: setupHeroCards()
  --------------------------------
  Controls the smooth 3D circular rotation (swiping, clicking,
  and auto-rotating in a circle).

================================================================
  13. IMAGES
================================================================

  FOLDER: images/
  --------------------------------
  Place your image files inside the images/ folder.
  Name them to match the "image" field in script.js

  Example:
    item has:  image: "images/cappuccino.jpg"
    So put:    images/cappuccino.jpg  in the images folder

  If an image file is missing, the website automatically shows
  a beautiful dark placeholder with the category icon.

================================================================
  14. RTL (Right-to-Left for Arabic & Kurdish)
================================================================

  FILE: style.css
  --------------------------------
  - RTL mode is applied automatically when language is switched
  - body.rtl { direction: rtl; }
  - Special RTL overrides for badges, search icon, etc.
    Look for selectors starting with: body.rtl

  FILE: script.js → setLanguage() function
  --------------------------------
  The function adds/removes the "rtl" class automatically.
  You don't need to touch this.

================================================================
  15. SOCIAL MEDIA & LOCATION LINKS (Top Header Bar)
================================================================

  FILE: index.html — Look for: <nav class="top-social-bar">
  --------------------------------
  Each icon has an <a href="#" ...> link.
  Whenever you want to add or change your links, just replace "#" with your real URL:

  1. Instagram:
     <a href="https://instagram.com/your_account" class="social-btn instagram" ...>

  2. Facebook:
     <a href="https://facebook.com/your_page" class="social-btn facebook" ...>

  3. TikTok:
     <a href="https://tiktok.com/@your_account" class="social-btn tiktok" ...>

  4. WhatsApp:
     <a href="https://wa.me/9647XXXXXXXXX" class="social-btn whatsapp" ...>

  5. Snapchat:
     <a href="https://snapchat.com/add/your_username" class="social-btn snapchat" ...>

  6. Location (Google Maps):
     <a href="https://maps.google.com/?q=your_coordinates" class="social-btn location" ...>
